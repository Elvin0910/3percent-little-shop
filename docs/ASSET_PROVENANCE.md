The seven PNG files in `dist/assets/` were recovered byte-for-byte from the Owner's original **3% Little Shop** Sites V3 source project, commit `bb2a0cab725efd3d63260943cc157c84d56363c1`. The original project documentation calls them generated concept art and illustrative placeholders. No stock-photo URL, third-party asset package, or separate license file was present in that source tree. The Owner requested this private source backup. This record establishes source lineage, not an independent legal opinion about every possible input to the original images.
